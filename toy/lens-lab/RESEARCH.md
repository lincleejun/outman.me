# 镜头成像 3D 模拟 — 研究笔记

日期 2026-09-23。起点：Ryan Sael 的推文（https://lens.lab.sael.net，Opus 5.5 一次生成，1h26m，$25.66）。

## 1. 推文那个站点是怎么做的（读了源码）

单文件 HTML + three.js 0.183，约 145 KB。它**不是真实光学模拟**，是一个"薄透镜公式 + 装饰性玻璃 + 深度图散景后处理"的教学演示：

- **成像公式只有一条**：弥散圆直径（占画幅高的比例）`coc = K_B/N * |1/dF - 1/D|`，dF 对焦距离，D 物距，N 光圈。景深边界由 `C_OK`（可接受弥散圆）反解。对焦环角度与 1/dF 线性（"像真的螺旋"）。
- **7 片"镜片"是纯装饰**：`ELEMS` 里每片只有 x 位置、半高 h、中心厚 t、前后曲率 r1/r2，用 LatheGeometry 车出玻璃形状。曲率**不参与任何计算**。对焦时整组玻璃沿轴平移（unit focusing），前镜筒伸出。
- **光线是画出来的，不是追出来的**：每个被摄点发出一束射线，到前镜片 → 在镜筒内平行 → 到后组后按薄透镜结果汇聚到毛玻璃（或形成一个圆盘）。汇聚点/圆盘半径直接用上面的 coc 算。
- **"照片"是后处理**：在入瞳位置放一个普通 three.js 相机渲染山谷（带深度），然后 fragment shader 按每像素深度算 coc，做 gather 模糊，采样核是 n 边形（模拟光圈叶片）→ 多边形散景。场景渲染与对焦无关，所以五张 film strip 只重跑模糊。
- 其余是产品化：GTAO、bloom、镜面地板、爆炸视图、导览镜头、卡片文案。

**结论**：它演示的是"对焦平面扫过场景"这一个概念，做得很漂亮，但换镜头对它没有意义。你想做的是下一层：真处方、真追迹。

## 2. 数据从哪来：厂商 spec 不够，要用专利

厂商官网公开的：焦距、最大光圈、最近对焦距离、最大放大率、片/组数、结构图（图片）、特殊玻璃标注（ED/非球面）、对焦方式（内对焦/后组对焦/整组）。**没有曲率半径、厚度、玻璃折射率**，光凭这些无法追迹。

完整处方（optical prescription）在**专利的数值实施例表**里，几乎所有日系厂（Sony/Canon/Nikon/Sigma/Tamron）都公开：

| 表 | 内容 |
| --- | --- |
| 面数据 | 每面：曲率半径 r、到下一面的间隔 d、d 线折射率 nd、阿贝数 νd、有效半径；非球面打 `*` |
| 非球面系数 | 圆锥系数 k 和 A4/A6/A8/A10… |
| 可变间隔 | 对焦（无限远 / 中距 / 最近）或变焦各状态下的 d_i 值 —— **这就是"哪个组在动、动多少"** |
| 系统值 | f、F no.、半视角、像高、总长、后焦 |

来源：

- **Google Patents**（免费）。搜 assignee + "imaging lens" + 焦距/光圈，或从下面的 Hub 反查专利号。
- **PhotonsToPhotos Optical Bench Hub**（Bill Claff）：1280+ 条**已匹配到量产镜头**的专利处方，浏览器内 2D 追迹，能播放对焦/变焦。是找"某镜头对应哪个专利"最好的索引。但 `OpticalBench.js` 是混淆过的 750 KB，数据不可直接抓；用它查专利号，再去专利里抄表。https://www.photonstophotos.net/GeneralTopics/Lenses/OpticalBench/OpticalBenchHub.htm
- **nzhagen/LensLibrary**（GitHub，MIT）：81 个专利镜头（1894–1998 经典结构：Sonnar、Tessar、Cooke、Planar…），每个有 `.zmx` + 文本处方 + 结构图。适合当起步数据集。https://github.com/nzhagen/LensLibrary
- **Dan Reiley 的 lens designs 站**：Zemax 存档文件（1897–2013）。https://sites.google.com/site/danreiley/a-file-exchange-site-for-lens-designs

注意：专利实施例 ≠ 量产镜头，通常"很接近"。做教学/可视化足够。

## 3. 物理模型分几层，各要什么

1. **薄透镜**（推文的层）：`1/f = 1/s + 1/s'`，coc 公式。只要 f、N。
2. **高斯/厚透镜**：主面、焦点，ABCD 矩阵逐面乘。需要 r、d、n。可以精确算 EFL/BFL/主面位置，pbrt 用它算"对焦要把后组挪多少"。
3. **顺序精确追迹**：每面求射线与球面交点，Snell 定律折射；孔径光阑挡射线。得到真实像点、弥散斑形状、球差、彗差、场曲、畸变。需要 r、d、n、有效半径。
4. **非球面**：sag 公式 `z = c r²/(1+√(1-(1+k)c²r²)) + A4 r⁴ + …`，交点用牛顿迭代。现代镜头几乎都有。
5. **色散**：νd → 三波长折射率（Cauchy 近似或 Sellmeier，玻璃牌号可查 Schott 目录）。出紫边/轴向色差。
6. **成像渲染**：pbrt 的 Realistic Camera（Kolb 1995）：从传感器每像素向后发射射线，穿过全部镜片进入场景。物理正确，自动得到光晕、散景形状、暗角、畸变。https://pbr-book.org/3ed-2018/Camera_Models/Realistic_Cameras

pbrt 的镜头文件格式就是四列文本：`曲率半径 厚度 折射率 孔径直径`，半径 0 = 光阑。够用，加两列 νd 和非球面系数、再加一个"组编号 + 各对焦状态间隔表"就是我们的 JSON。

## 4. 对焦怎么模拟

- **整组伸缩**（老镜头、推文的做法）：整个镜头前移 δ，传感器不动。δ 用追迹二分求解（见 trace.py），薄透镜估算 `f²/(D−f)`。
- **内对焦/浮动组**（现代镜头）：专利给了各状态的可变间隔，直接插值 d_i。不用解，照表动。
- 视觉上：3D 里每片玻璃属于某个组，组的 x 位置 = 累加间隔，改间隔 → 玻璃真的在动，射线真的重新追。

## 5. 已验证（trace.py）

用 LensLibrary 的 Bertele 1934 Sonnar 9.2cm f/1.5（US 1,975,678，11 面）写了 ~80 行纯 Python 子午面顺序追迹：

```
EFL 92.550 mm (Zemax 92.55012)   BFL 34.751 mm (Zemax 34.75113)
object    inf mm -> lens extension  0.000 mm, on-axis spot radius f/1.5  640.6 µm, f/8   5.9 µm
object   3000 mm -> lens extension  3.040 mm
object   1000 mm -> lens extension 10.571 mm
```

焦距/后焦与 Zemax 一致到 1e-4 mm。全开时球差把轴上光斑撑到 0.6 mm（近轴焦面、最大半径，非最佳焦面），收到 f/8 变 6 µm —— 这就是 1934 年 f/1.5 镜头"全开软、收光圈锐"的物理原因，模拟直接给出来了。

## 6. 建议架构（做的时候）

- **单 HTML + three.js**，推文已证明这个形态够用且好分享。
- **镜头 = JSON**：`{name, f, N, surfaces:[{r,t,n,vd,h,asph?,group}], focus:[{D, gaps:{...}}]}`。先手抄 2–3 个（一个 LensLibrary 经典 + 一个现代专利，如 Sony 50/1.4 GM 或 Nikon Z 50/1.8 S）。
- **玻璃几何**：按 r1/r2/t/h 车 LatheGeometry，与推文 `lensGeo` 同思路，但参数来自处方，所以形状是真的。
- **射线**：CPU 追迹（几百到几千条/帧足够），画成线；轴上 + 两个视场、每束 N 条填满入瞳；光阑挡掉的射线画到光阑为止。这一步就能看到球差、彗差、像面弯曲、光阑收缩效果。
- **成像**两条路，先 A 后 B：
  - A. 推文的深度 coc 后处理，但 coc(D) 不用薄透镜公式，改查追迹得到的真实光斑半径表（含光圈、含离轴）。便宜，一晚上能做。
  - B. fragment shader 里真做 Realistic Camera：每像素若干射线穿过 N 面到场景（场景用 SDF 或几个解析物体）。慢但物理正确，能出真散景形状/暗角/畸变。
- **色散**：三波长各追一次，射线按 RGB 着色，就能"看见"色差。

## 7. 未做 / 有意省略

- 没抓 Optical Bench 的数据（混淆 + 版权），只用它当索引。
- trace.py 只做子午面、球面、单波长、无光阑遮挡；非球面/色散/斜射线是下一步，数据格式已预留。
- 没找具体现代镜头的专利号：需要人在 Hub 里点开目标镜头看 patent number，再去 Google Patents 抄表。

## 8. MVP：Summilux-M 35mm f/1.4 Aspherical "AA"（2026-09-23）

`index.html`（单文件，three.js CDN）· `node test.mjs` 校验追迹器。本地看：`python3 -m http.server 8765` 后打开 `http://localhost:8765/`。

- **处方来源**：PhotonsToPhotos Hub 把 "Summilux-M 35mm F1.4 Asph v1" 对到 **US 5,161,060 例 1**（Walter Watz / Leica，1990）。9 片 5 组，第 4、13 面非球面，n_e/ν_e（546 nm）。专利没给口径，按图 1 比例估，再保证 f/1.4 轴上光束能全通过。
- **大坑**：Leica 非球面公式 `p(s)=Σ K(n)(s²/2)^n` 里的 s 是**弦长**（镜面点到顶点的直线距离，s²=r²+p²），不是径向高度。当成高度算，f/1.4 轴上光斑 294 µm；改成弦长后 12 µm，与专利"<20 µm"一致。这种写法下 K(1)=1/R 单独就是精确球面。
- **对焦**：M 口螺旋整组外移（专利说近距到 0.7 m 仍保持，无浮动组）。求解外移量使近轴像落回无穷远像位。
- **Sonnar 1934**：Zemax 的后焦是近轴像面，f/1.5 球差大，底片改放在全开最佳焦面（前移 1.32 mm），于是收光圈会出现真实的焦点漂移。
- **成片**：各深度层用追迹光斑的 50% 能量半径换算高斯模糊；街灯逐盏用真实光斑图盖印成散景（含离轴猫眼、色差）。

校验结果（`node test.mjs`）：

| 项 | 追迹 | 专利 / Zemax |
| --- | --- | --- |
| Summilux 焦距 | 35.41 mm | 35 |
| 近轴后焦 | 19.636 mm | 截距 19.595 |
| 畸变 @ 像高 12 | −0.98% | −0.871% |
| 畸变 @ 像高 21 | −1.10% | −1.061% |
| 0.7 m 放大率 | 1:17.4 | 1:17.5 |
| 轴上 rms f/1.4 · f/5.6 | 12.2 · 1.1 µm | <20 µm |
| Sonnar 焦距 / 后焦 | 92.550 / 34.751 | 92.550 / 34.751 |

没做：非球面以外的斜光线像差图、玻璃 Sellmeier（现在用 Abbe 数推 Cauchy）、镜片间杂光/鬼影、光圈叶片形状、逐像素真追迹成像。

## 9. 第二版：布景、单条光线、光圈、M6 机身、波前（2026-09-23）

- **布景**：成片的四个图层（天空、城市、星标、叶子）挂在镜头前，距离按对数压缩，但每个物体相对入瞳的角度是真的；视场金字塔和距离刻度一起画出。光线从布景上的物点出发。
- **单条光线**：点击任意光线，高亮成白管并画出每一面的法线；表格逐面给出高度、折射前后与光轴的夹角、折射率变化，以及"向光轴折（会聚）/离光轴折（发散）"。
- **光圈**：3D 叶片 + 正视小图 + 进光量百分比；被叶片挡住的光线画成红色并止于叶片；被镜片边缘挡住的就是渐晕。标签写明光阑在 G2 与 G3 之间、镜头中部。叶片数为示意。
- **机身**：Leica M6（138 × 77 × 33.5 mm，胶片在卡口后 27.8 mm），可剖开看胶片。
- **聚光/扩光的表现**：Huygens 波前按真实光程等值画（光在玻璃里慢 n 倍，所以波前被掰弯）；光锥是逐方位二分求出的真实通光边界；镜片按自身光焦度着色（蓝会聚、粉发散）。参考 Ciechanowski《Cameras and Lenses》的讲法。
- **核对**：各组光焦度 G1 +92、G2 −179、G3 +60、G4 +77 mm，与专利权利要求的 + − + + 一致；G5 近轴几乎为零（+909 mm），专利称其为负，这里如实显示为"校正像差"。
