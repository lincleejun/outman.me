# Sharing pages
Whenever an HTML page — report, diff, mockup, chart, dashboard, anything someone else will open — needs to be shared, use the `share-page` skill and hand back the `share.outman.cc` link. Never publish it with the Artifact tool or any third-party host. To find, download or search something shared earlier, use the same skill's `share list|get|grep`.
